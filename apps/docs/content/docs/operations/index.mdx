---
title: Operations
description: Keep a production Mise installation healthy and recoverable.
---

A reliable Mise installation has four operational properties:

1. A stable `JWT_SECRET` and accurate `WEB_ORIGIN`
2. Durable PostgreSQL storage with tested backups
3. HTTPS for any deployment reachable from the internet
4. Deliberate, reversible upgrades
