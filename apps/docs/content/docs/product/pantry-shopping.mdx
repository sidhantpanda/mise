title: Pantry and shopping
description: Keep household inventory and the shared shopping list close to the meal plan.
---

## Pantry locations

Inventory can be grouped into pantry, fridge, and freezer. Adding an item that is
already present restocks it instead of creating a second copy.

## Shopping list

Shopping items have a name, optional quantity and category, and a checked state. You
can add items manually or populate the list from a recipe. When recipe ingredients
are added, Mise skips existing unchecked entries.

The list is shared by the active workspace, so household members see changes without
passing a separate list around.
